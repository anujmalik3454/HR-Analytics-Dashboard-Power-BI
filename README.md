# HR Analytics Dashboard | Power BI

Interactive HR Analytics Dashboard built using Power BI to analyze employee data, salary, performance, experience, workload, and hiring trends.

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel
- Data Cleaning
- Data Visualization

## Project Overview

This project focuses on analyzing employee workforce data and presenting meaningful HR insights through an interactive Power BI dashboard.

## Key Analysis

- Employee workforce analysis
- Department-wise analysis
- Salary analysis
- Performance analysis
- Experience analysis
- Workload and project hours
- Hiring trends
- KPI analysis

## Dashboard

Interactive Power BI dashboard with KPI cards, charts, slicers, and filters.
